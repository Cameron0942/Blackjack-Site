# Calculator Web App

A modern, responsive calculator built with HTML, CSS, and JavaScript featuring:

## Features

- **Beautiful Design**: Modern gradient interface with smooth animations
- **Full Functionality**: Basic arithmetic operations (+, -, ×, ÷)
- **Keyboard Support**: Use your keyboard for quick calculations
- **Responsive Design**: Works perfectly on desktop and mobile devices
- **Visual Feedback**: Button press animations and ripple effects
- **Smart Display**: Shows calculation history and current result
- **Error Handling**: Prevents division by zero and invalid operations

## Usage

Simply open `index.html` in your browser to start using the calculator.

### Keyboard Shortcuts

- **Numbers (0-9)**: Input numbers
- **Operators (+, -, *, /)**: Perform operations
- **Enter or =**: Calculate result
- **Escape**: Clear all
- **Backspace**: Delete last input
- **Period (.)**: Add decimal point

## Controls

- **C**: Clear all input
- **CE**: Clear current entry
- **⌫**: Delete last character
- **=**: Calculate result

Built with modern web technologies and responsive design principles.
